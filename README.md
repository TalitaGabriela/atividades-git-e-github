# Atividade 1 - Git e GitHub

Projeto de exemplo criado para a disciplina de Gerência de Serviços de Internet (TADS 04), com o objetivo de praticar o fluxo básico do Git e do GitHub.

## Estrutura do projeto

- `index.html` - página principal
- `style.css` - estilos da página
- `script.js` - interatividade da página
- `img/` - imagens utilizadas no `index.html`
- `erro.txt` - anotações de erros encontrados durante o desenvolvimento
